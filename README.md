# Aprendizagem HTML

Repositório dedicado ao registro da minha jornada de estudos em HTML, contendo exemplos práticos, exercícios e pequenos projetos desenvolvidos ao longo do aprendizado.

Página publicada via GitHub Pages: [lucasemanuel3473.github.io/Learning-Html](https://lucasemanuel3473.github.io/Learning-Html/)

---

## Objetivo

Este repositório tem como finalidade documentar de forma estruturada o processo de aprendizado de HTML, desde os conceitos fundamentais até tópicos mais avançados, como semântica, formulários e acessibilidade.

## Progresso

- [x] Estrutura básica de um documento HTML (`<!DOCTYPE>`, `<html>`, `<head>`, `<body>`)
- [x] Tags de texto e formatação (`<h1>` a `<h6>`, `<p>`, `<br>`)
- [ ] Links e imagens
- [ ] Listas ordenadas e não ordenadas
- [ ] Tabelas
- [ ] Formulários
- [ ] Semântica HTML5 (`<header>`, `<main>`, `<footer>`, `<section>`)
- [ ] Acessibilidade básica
- [ ] Introdução ao CSS
