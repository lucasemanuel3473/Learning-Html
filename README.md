Aprendizagem HTML

Repositório dedicado a registrar minha jornada de estudos em HTML, com exemplos práticos, exercícios e pequenos projetos conforme vou aprendendo.

Veja publicado no GitHub Pages: lucasemanuel3473.github.io/Learning-Html


Objetivo

Este repositório serve como um diário de estudos, onde documento o que aprendo sobre HTML — desde a estrutura básica de uma página até conceitos mais avançados como semântica, formulários e acessibilidade.

Progresso


 Estrutura básica de um documento HTML (<!DOCTYPE>, <html>, <head>, <body>)
 Tags de texto e formatação (<h1>–<h6>, <p>, <br>)
 Links e imagens
 Listas (ordenadas e não ordenadas)
 Tabelas
 Formulários
 Semântica HTML5 (<header>, <main>, <footer>, <section>)
 Acessibilidade básica
 Introdução ao CSS
